**f2b-api** — публичный API для поиска IP-адресов, которые Fail2ban зафиксировал на нескольких серверах.

Раньше я уже публиковал статистику Fail2ban в виде HTML-отчётов. Но если нужно найти определённый IP или понять, в каких jail он встречался, листать отчёты неудобно. Поэтому я добавил поиск по IPv4/IPv6, фильтры, статистику по странам и ASN и текстовый список уникальных IP.

Здесь важно не перепутать две вещи: **IP, попавший в базу, не обязательно принадлежит злоумышленнику**. Запись означает лишь, что журнал одного из серверов совпал с настроенным фильтром Fail2ban. Общий IPv4 за CGNAT, повторная выдача динамического адреса и ложные срабатывания не позволяют по одной записи определить человека или доказать злой умысел.

## Быстрый старт

GET-запрос можно выполнить прямо в [интерактивном справочнике API](https://api.f2b.0xhw.com/docs) или через curl:

```sh
curl 'https://api.f2b.0xhw.com/v1/stats' | jq
curl 'https://api.f2b.0xhw.com/v1/ips?limit=10' | jq
```

- [Справочник API и вызовы из браузера](https://api.f2b.0xhw.com/docs)
- [Спецификация OpenAPI 3.1](https://api.f2b.0xhw.com/openapi.json)
- [Текущая статистика](https://api.f2b.0xhw.com/v1/stats)
- [Активные IP-адреса](https://api.f2b.0xhw.com/v1/ips)
- [Существующие HTML-отчёты](https://soulminingrig.com/f2b-report/)

## Что публикуется

Публикуются метки источников, имена jail, IP-адреса, время первого и последнего наблюдения, текущий статус блокировки, страна, ASN и организация. **Сырые журналы запросов, имена учётных записей, секреты и административные списки исключений не публикуются.**

Для чтения данных аутентификация не нужна. Публичный API не может отправлять наблюдения или управлять межсетевыми экранами серверов. О схеме сбора данных можно прочитать в разделе [О сервисе]({{< relref "/about/_index.md" >}}), а о значении полей — в разделе [Как читать данные]({{< relref "/data/_index.md" >}}).
