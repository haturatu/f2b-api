## 観測の単位

1 件の観測は `source`、`jail`、`ip` の組み合わせです。同じ IP が二つの Jail や収集元で検知されれば、複数の観測として保持します。

統計の `observations` は観測の件数、`ips` は重複を除いた IP の数です。テキストフィードも IP の重複を除きます。

## 時刻と状態

| 項目 | 意味 |
| --- | --- |
| `first_seen` | この収集基盤で最初に確認した時刻 |
| `last_seen` | 最後に確認した収集時刻 |
| `active = 1` | 最新のスナップショットの BAN 一覧に存在 |
| `active = 0` | 後続のスナップショットで一覧から外れた状態 |
| `stale = 1` | Jail の最終収集から 48 時間を超えて更新がない状態 |

時刻は BAN イベントそのものの発生時刻ではありません。収集元が停止しても BAN 解除とは扱いません。更新が古い Jail は、現在有効な一覧・統計・フィードから除外します。検索と `active=all` では過去の観測を確認できます。

## 定期収集の制約

収集元では日次のレポート生成と合わせ、現在の BAN 一覧を JSON にします。内容に変更がなければハッシュを使った heartbeat を送り、変更があれば完全なスナップショットから差分を反映します。

収集と収集の間に BAN されて解除された IP は記録できません。過去の BAN 一覧すべてを復元する API でもありません。記録はこの収集基盤が観測を始めた時点以降のものです。

## 国・ASN・組織

これらは GeoIP や RDAP などによる付加情報です。不明な値は `null` になります。国コードや ASN はネットワーク情報であり、アクセスした人物の国籍、居住地、所属、個人の特定を示すものではありません。

## 公開範囲

公開 API は IP、公開用の収集元ラベル、Jail、観測時刻、状態、ネットワークの付加情報を提供します。生のアクセスログ、リクエスト本文、アカウント名、認証情報、管理用の除外リストは公開しません。

IP の記録だけで悪意を断定したり、恒久的な自動遮断の根拠にしたりせず、[検知条件]({{< relref "/policies/_index.md" >}})と状態を確認してください。共有回線や動的な IP 割り当てでは、観測時とは異なる利用者が使っている場合があります。

## 誤検知や仕様の報告

公開データの解釈や仕様の不整合については、[GitHub リポジトリ](https://github.com/haturatu/f2b-api)から報告できます。認証情報、生ログ、個人情報を含む内容は公開しないでください。修正の検討では、Jail、観測時刻、問題の条件を切り分けて確認します。
